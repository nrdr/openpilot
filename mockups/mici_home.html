MICI · Design Notes

Canvas: 536 × 240 logical px (1.9" OLED, 300 PPI). Aspect 2.23:1 — squat letterbox. At 1× the prototype renders ~3× larger than the actual device on a 96 DPI display.

Information hierarchy

  • Wordmark anchors the home — 96 px display weight, gradient blue→cyan, kept fully visible. Recolors amber for experimental, grey for offline.
  • A soft aurora behind the wordmark breathes at 3.6 s, tinted by current state — life without clutter.
  • State pill carries the canonical state ("STANDARD · READY") with a pulsing color dot.
  • Meta strip is just network + branch. No date, no hash, no version — diagnostic noise lives in Settings → Developer.

Navigation pattern

  • Top-right gear → Settings landing — 5 full-height tiles, no vertical scroll-list.
  • Tap a category → full-screen sub-panel slides in from the right.
  • Sub-panels are horizontal pagers: one setting per page. A tappable hand can't reliably scroll a 240 px-tall list, so we sidestep it entirely.
  • Each panel shows a counter ("3/8") in the topbar and a row of dots above the bottom edge — current page is the elongated cyan dot.

Interactions

  • Swipe the panel body left/right to page. Edge resistance hints at the boundary. Tap-slop < 8 px is treated as a tap (so a stray drag doesn't flip a toggle).
  • Long-press (≥500 ms) anywhere on the home body toggles experimental mode in place; a top progress strip fills as you hold so the press is felt.
  • setPointerCapture is used during drag; on release we resolve the tap target via document.elementFromPoint, since pointer capture redirects e.target.
  • Pointer events drive everything — one path for mouse, touch, pen.

Aesthetic

  • Blue/black radial gradient on every screen for cohesion.
  • Monochrome white inline SVG icons with a soft blue drop shadow — no emoji, no color icons.
  • Status color used sparingly: green ready, amber experimental, grey offline, red destructive only.
